# BIOTHOMAS — Standalone HTML Prototype

Client-side storefront prototype with the green/black brand palette. **Not connected to Shopify** (or any backend). Cart and checkout are simulated in the browser.

## Run locally

```bash
./serve.sh
# → http://127.0.0.1:8765/index.html
```

Optional port: `./serve.sh 9000`

## Brand

- **Logo:** `logo.png` (BIOTHOMAS)
- **Accent green:** `#24A844`
- **Ink / black:** `#121212` / `#000000`
- **Soft ground:** `#F4F7F4`
- **Fonts:** Montserrat (display) + Outfit (body)

## Notes

- Based on the archived prototype in `archive/prototype/`
- Alpine.js + Tailwind CDN only — no theme CLI, no Liquid, no store APIs
