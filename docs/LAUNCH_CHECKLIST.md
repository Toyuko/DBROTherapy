# BIOThomas — Launch Checklist

Do not publish until every **P0** item is complete.

## P0 — Blockers

- [ ] Legal business details confirmed (name, address, email, phone)  
- [ ] Privacy / Terms / Refund / Shipping policies published  
- [ ] Medical/wellness disclaimer approved  
- [ ] Product catalog live with confirmed prices + inventory  
- [ ] Product photography uploaded (machines at minimum)  
- [ ] Logo (light + dark as needed) + favicon + OG image  
- [ ] Payments enabled and tested (test order)  
- [ ] Shipping rates configured (remove unverified “free global” claims if false)  
- [ ] Taxes / markets configured  
- [ ] Support email monitored  
- [ ] Theme QA checklist completed  
- [ ] Password page removed / store opened  
- [ ] **biothomas.com** connected as primary domain (HTTPS + www redirect decided)  
- [ ] Smoke test on `https://biothomas.com` (not only the `*.myshopify.com` URL)  

## P1 — Strongly recommended

- [ ] About + Services copy finalized  
- [ ] At least 3 real testimonials or section hidden  
- [ ] Blog posts for Featured Articles or section hidden  
- [ ] Clinical demo video embedded on Science page  
- [ ] Reviews app connected  
- [ ] Metafields populated for machines  
- [ ] Compare page linked to real products  
- [ ] 301 redirects from any old marketing URLs  
- [ ] Analytics (Shopify + optional GA/Meta)  

## P2 — Post-launch

- [ ] Self-hosted fonts  
- [ ] Instagram feed decision  
- [ ] Case studies / press  
- [ ] B2B / clinic inquiry workflow  
- [ ] Ongoing Lighthouse monitoring  

## Launch day

1. Final theme publish  
2. Place test order end-to-end  
3. Verify order notification emails  
4. Smoke-test mobile home + PDP + checkout  
5. Announce only after smoke test passes
